### Phase 1: اختبار الوحدة (Unit Testing)

#### 1.1 اختبار `kMeansClusterization()`

**الاختبار:**
```typescript
// اختبار تصنيف صحيح للمتحدثين

  { start: 3, end: 3.8 },  // طفل 1 (طاقة أعلى)
  { start: 4.2, end: 5 },  // طفل 2 (طاقة أعلى)
];
// الكتلة الأولى: معلم (RMS منخفض)
// الكتلة الثانية: أطفال (RMS مرتفع)
```

**المعايير:**
- ✅ تصنيف صحيح > 95% من الحالات
- ✅ السرعة < 500ms

#### 1.2 اختبار `mergeToTarget()`

**الاختبار:**
```typescript
// لدينا 9 مقاطع، نريد 7
const regions = [
  { start: 0, end: 0.5 },
  { start: 0.6, end: 1.1 },
  // ... 7 مقاطع إضافية
];
const result = mergeToTarget(regions, 7, data, sr);
// يجب أن ندمج المقاطع الأقصر ذات الفجوات الأصغر
```

**المعايير:**
- ✅ العدد النهائي = الهدف (7)
- ✅ الدمج الذكي يفقد أقل معلومات
- ✅ عدم فقدان أي آيات

#### 1.3 اختبار `splitToTarget()`

**الاختبار:**
```typescript
// لدينا 5 مقاطع، نريد 7
const regions = [
  { start: 0, end: 2 },    // طويل جداً
  { start: 2.5, end: 4 },  // متوسط
  // ... مقاطع إضافية
];
const result = splitToTarget(regions, 7, data, sr);
// يجب تقسيم المقاطع الطويلة عند أهدأ نقطة
```

**المعايير:**
- ✅ العدد النهائي = الهدف (7)
- ✅ كل جزء يحتوي على صوت حقيقي (RMS > 0.001)
- ✅ عدم القطع في منتصف الكلمة

#### 1.4 اختبار `refineEdges()`

**الاختبار:**
```typescript
// مقطع بفراغات في الحواف
const region = { start: 0.5, end: 2.5 };
// الفراغ الفعلي: 0.7 - 2.3
const refined = refineEdges(region, data, sr, threshold);
// يجب أن تكون الحواف المكررة: ~0.7 - 2.3
```

**المعايير:**
- ✅ الحواف الجديدة > 10ms أقرب للصوت الفعلي
- ✅ لا تقطع أي جزء من الصوت الحقيقي
- ✅ الدقة ≥ 10ms

### السيناريو 1: ملف صوتي منخفض الجودة
```
الملف: صوت منخفض الكفاءة / ضوضاء محيطة
الاختبار: هل تعمل الخوارزمية بشكل صحيح؟
المعايير: دقة ≥ 80% مقبول
```

### السيناريو 2: ملف صوتي عالي الجودة
```
الملف: تسجيل احترافي
الاختبار: هل تصل للدقة القصوى؟
المعايير: دقة ≥ 98% متوقعة
```

### السيناريو 3: أصوات متقاربة (معلم + أطفال)
```
الملف: أصوات متشابهة الطاقة
الاختبار: هل يميز بينهما بشكل صحيح؟
المعايير: تصنيف صحيح > 90%
```

### السيناريو 4: فراغات طويلة بين الآيات
```
الملف: فراغات 2-3 ثانية بين الآيات
الاختبار: هل يتعامل مع الفراغات الطويلة؟
المعايير: دقة ≥ 95%
```

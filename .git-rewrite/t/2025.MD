## Detailed Code & Component Walkthrough

### 1. Audio Playback Fallback (`CustomPlayer.tsx` & `QuranReader.tsx`)
- Added `onError` event handler to `CustomPlayer.tsx`:
```tsx
onError={() => {
  if (!fallbackToCloud) {
    console.warn("Local audio playback failed, falling back to cloud audio stream...");
    setFallbackToCloud(true);
  } else {
    setError(true);
    setLoading(false);
  }
}}
```
- Added `onError` handler to `<audio ref={audioRef}>` in `QuranReader.tsx`:
```tsx
onError={() => {
  if (selectedSurah && audioRef.current && audioRef.current.src !== selectedSurah.src) {
    audioRef.current.src = selectedSurah.src;
    audioRef.current.load();
    audioRef.current.play().catch(() => {});
  }
}}
```

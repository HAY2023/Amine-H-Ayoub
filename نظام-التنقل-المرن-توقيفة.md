## ملخص النظام

يتكون نظام التنقل من ثلاثة أوضاع:

| الوضع | السلوك |
|-------|--------|
| 🎧 **الوضع العادي (pure)** | منع كامل لأي وصول للأطفال - لا يظهر أي شيء متعلق بالأطفال |
| 🔄 **وضع التنقل المرن (flexible)** | إمكانية الوصول لركن الأطفال والتبديل بين الأوضاع |
| 👶 **وضع الأطفال (kids)** | تفعيل كامل لميزات الأطفال |

```typescript
// علامة الوضع العادي الصارم
const PURE_MODE_KEY = "mushaf:pureMode";

export const isPureMode = (): boolean => {
  if (typeof window === "undefined") return false;
  try { return localStorage.getItem(PURE_MODE_KEY) === "1"; } catch { return false; }
};

export const setPureMode = (on: boolean) => {
  if (typeof window === "undefined") return;
  try {
    localStorage.setItem(PURE_MODE_KEY, on ? "1" : "0");
    if (on) setKidsHidden(true);
  } catch { /* ignore */ }
  window.dispatchEvent(new Event("mushaf:appmode"));
};

// هل ركن الأطفال مُفعَّل؟
export const kidsEnabled = (): boolean => !kidsHidden() && (!isPureMode() || getAppMode() !== "parent");

// منع الوصول لصفحات الأطفال
export const kidsRouteBlocked = (): boolean => {
  if (isPureMode()) return true;
  return kidsHidden() && !isMushafDevEnabled();
};
```

## منطق العمل

### عند اختيار الوضع العادي (pure):
1. `setPureMode(true)` → يمنع أي وصول للأطفال
2. `setKidsHidden(true)` → يخفي الأطفال من الواجهة
3. `isPureMode()` يُرجع `true` في كل التطبيق

### عند اختيار وضع التنقل المرن (flexible):
1. `setPureMode(false)` → يسمح بالوصول للأطفال
2. `setKidsHidden(false)` → يظهر الأطفال في الواجهة
3. `isPureMode()` يُرجع `false`

### عند التبديل بين الأوضاع في ProfilePicker:
- **"لي نفسي"**: لا يغير `pureMode` (يبقى كما هو)
- **"لأطفالي"**: `setPureMode(false)`

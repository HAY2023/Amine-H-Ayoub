# قرار التكنولوجيا: الاستمرار بـ React + Tauri أم الانتقال إلى Flutter؟

## الخلاصة التنفيذية
- هذا تطبيق **PWA + Tauri** مكتمل (169 ملف TypeScript في `src/`).
- ينشر حالياً على المتصفح (PWA) + ويندوز + ماك + لينكس + أندرويد + **Android TV**.
- **الكود "يُترجم" إلى Flutter عبر أداة** — بل يُعاد بناؤه يدوياً بالكامل بلغة Dart، وهذا عملٌ يقاس بالشهور، وليست ساعات أو أيام.

## مقارنة "يعمل على كل الأجهزة"
| الجهاز | الوضع الحالي (React+Tauri) | بعد الانتقال لـ Flutter |
|---|---|---|
| أندرويد موبايل | ✅ | ✅ (أداء أصلي أفضل) |
| iOS | ⚠️ عبر PWA | ✅ تطبيق أصلي في متجر Apple |
| ويندوز / ماك / لينكس | ✅ | ✅ |
| المتصفح / الويب | ✅ فوري بدون تثبيت | ⚠️ أقل نضجاً من حيث التجربة |
| **Android TV** | ✅ مدعوم حالياً | ❌ لا دعم رسمي سلس — سيتعرقل كثيراً |
| أجهزة ضعيفة / قديمة | ✅ خفيف نسبياً | ⚠️ قد يحتاج مواصفات أعلى |

## ما يستحق فعلاً إعادة البناء
1. **مشغّل الصوت المتقدم** (AutoNext، تكرار، MediaSession، تشغيل خلفي، كاش صوتي):
   في Flutter بديل قوي عبر `just_audio` + `audio_service`.
2. **المصحف والقراءة التفاعلية** (*QuranReader* 76KB و *RecitationMethods* 96KB):
   إعادة تصميم كامل للواجهات والتفاعل العربي RTL.
3. **التعرّف على الصوت (كشف المتحدث: معلم/طفل)** عبر MFCC + ONNX Runtime:
   إعادة ربط بمكتبة OnnxRuntime لـ Dart/Flutter.
4. **المزامنة عبر Supabase** (ملفات تقدّم وألمكتب):
   يوجد SDK رسمي `supabase_flutter` — النقل سلس هنا.
5. **التخزين دون اتصال** (مجلدات Rust/Tauri للتلاوات):
   استبداله بمكتبة تخزين محلي (درع/306) ومسارات ملفات المستخدم.

## التكلفة والزمن
- تقدير مبدئي لفريق مطوّر واحد متفرغ: **من 3 إلى 6 أشهر** حتى نسخة تعادل الميزات الحالية،
  مع اختبارات ومراجعات لكل منصة (خاصة Android TV والسهرات).
- الأخطاء المكتشفة في بناء جديد على منصات الجميل في الغالب، وليست ترجمةً مباشرة.

## التوصية
1. **الاستمرار بالمكدس الحالي** (React + Tauri + PWA) ثم تحسين الأداء والتجربة =
   أفضل عائد، ويخدم كل الأجهزة بأنسب جودة، خاصة Android TV و PWA.
2. لو قررت التجريب في Flutter لهدف محدد (مثل أندرويد أو iOS بأداء أصلي):
   ابدأ **مشروعاً جديداً** يحل محلّ **المشغّل فقط** أولاً، مع إبقاء الويب/تلفزيونات على
   النظام الحالي، ثم وسّع تدريجياً.

# سيرفر الأسئلة لتطبيق القرآن للأطفال

هذا المجلد يحتوي على كود السيرفر الذي سيعمل على HuggingFace ليوفر واجهة برمجية (API) لتطبيق الأطفال. السيرفر سيقوم بتوليد واختيار أسئلة عشوائية وإرسالها للتطبيق.

## طريقة الرفع على HuggingFace

1. اذهب إلى [HuggingFace Spaces](https://huggingface.co/spaces) وسجل دخولك بحسابك.
2. اضغط على الزر الأصفر **Create new Space**.
3. اكتب اسم السبيس (مثلاً `learn-quran-kids-api`).
4. اختر الترخيص (مثلاً `mit`).
5. في قسم **Space SDK**، اختر **Docker** واختر **Blank**.
6. بعد إنشاء الـ Space، ستجد تبويب **Files**.
7. اضغط على **Add file** ثم **Upload files**، وقم برفع الملفات التالية الموجودة في هذا المجلد:
   - `app.py`
   - `requirements.txt`
   - `Dockerfile` (سنقوم بإنشائه الآن)

## طريقة اختبار السيرفر
بعد الرفع وتشغيل السبيس بنجاح، سيكون الرابط الخاص بالسيرفر كالتالي (استبدل username و spacename):
`https://username-spacename.hf.space`

قم بنسخ هذا الرابط لأننا سنضعه في إعدادات التطبيق.

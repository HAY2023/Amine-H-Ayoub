# 🎮 ألعاب الأطفال — ملف السيرفر (خارج كود التطبيق)

هذا المجلد هو **المكان الخاص لإضافة ألعاب جديدة بدون تحديث التطبيق**.

التطبيق يجلب هذا الملف تلقائياً عند فتح ركن الأطفال:

```
https://raw.githubusercontent.com/HAY2023/Amine-H-Ayoub/main/kids-games/games.json
```

## ➕ كيف تضيف لعبة جديدة؟

1. ضع لعبتك كـ HTML كامل (ملف واحد) داخل حقل `"html"` في `games.json`،
   أو ارفع ملف HTML في هذا المجلد واستخدم `"kind": "url"` مع رابط يستخدم `text/html` (مثل GitHub Pages).
2. أضف عنصراً جديداً في مصفوفة `"games"`:

```json
{
  "id": "my-new-game",
  "title": "لعبتي الجديدة",
  "desc": "وصف قصير يظهر تحت اللعبة",
  "icon": "Puzzle",
  "ageMin": 6,
  "cost": 20,
  "kind": "html",
  "html": "<!DOCTYPE html> ... كود لعبتك كاملاً ..."
}
```

3. ارفع التغيير (git push) — ستحصل عليه كل الأجهزة عند فتح ركن الأطفال من جديد، **دون أي تحديث للتطبيق**.

## 🔑 بروتوكول التواصل مع التطبيق (postMessage)

من داخل لعبتك:

```js
// إعطاء الطفل نجوماً (تُودع في محفظته — بحد أقصى 10 لكل رسالة و100 لكل جلسة)
parent.postMessage({ type: "nour:game:stars", amount: 1 }, "*");

// إغلاق اللعبة والعودة لقائمة الألعاب
parent.postMessage({ type: "nour:game:exit" }, "*");

// إشعار التطبيق أن اللعبة جاهزة (يرسل اسم الطفل ونجومه)
parent.postMessage({ type: "nour:game:ready" }, "*");
```

من التطبيق إلى اللعبة:

```js
// { type: "nour:game:profile", name: "اسم الطفل", coins: 123 }
window.addEventListener("message", function (ev) {
  var d = ev.data || {};
  if (d.type === "nour:game:profile") { /* استخدم d.name و d.coins */ }
});
```

## 🔒 الأمان

- كل لعبة تعمل داخل `iframe` معزول (`sandbox` بدون `allow-same-origin`) — لا يمكنها
  الوصول إلى بيانات التطبيق أو localStorage أو الكوكيز.
- النجوم الممنوحة من الألعاب محدودة (حماية من التلاعب).

## 💰 النقاط (المال)

- القراءة/الاستماع: **+5 نجوم لكل دقيقة** (المصدر الأساسي).
- الألعاب المدمجة: 1-3 نجوم لكل إجابة صحيحة (قليلة عمداً).
- كل لعبة لها `"cost"` — الطفل يفتحها بنجومه من محفظته (لعبة واحدة مجانية فقط).
